# Результаты экзаменов и данные инструктора

В панели администратора рядом с «Подробнее» добавлена кнопка «Удалить». Перед удалением выводятся название проверки, сотрудник, дата и подтверждение. Удаляется только выбранная попытка вместе с её ответами; она исключается из статистики. Удаление незавершённой попытки также прекращает доступ к ней. Сам экзамен и банк вопросов сохраняются.

При допуске к экзамену появились два необязательных поля: ФИО инструктора и жетон инструктора (123-456). Можно оставить оба пустыми или заполнить только одно. Если жетон указан, его формат проверяется браузером и сервером. Информация сохраняется в попытке, отображается администратору в «Подробнее» и включается в CSV. Старые записи продолжают работать без заполнения инструктора.

## Обновление через веб-ресурсы

1. Распакуйте `preview/fso-results-update.zip`.
2. Загрузите папки `site`, `supabase`, `tests` и эту инструкцию в корень существующего репозитория GitHub (Add file → Upload files), сохранив пути файлов. Дождитесь успешного завершения Actions.
3. В вашем GitHub Codespace обновите файлы (`git pull origin main`, предварительно сохраните собственные изменения, если они есть).
4. Выполните `npm test`, затем разверните обновлённую функцию с действующей авторизацией Supabase CLI:

```bash
npx --yes supabase@latest functions deploy fso-api --project-ref rnkmfpjzmvdnpijpeayw --no-verify-jwt --use-api
```

5. Обновите сайт Ctrl+F5. Создайте пробную попытку с данными инструктора, проверьте «Подробнее», затем удалите эту пробную попытку.

Обновлять нужно и интерфейс GitHub Pages, и серверную функцию Supabase. SQL-миграция не требуется. Пакет не содержит базу данных, ключи, пароли или `site/config.js`. Включён также актуальный вывод номеров подпунктов без слова «Часть».
