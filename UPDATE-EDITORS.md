# Обновление редакторов и типов вопросов

Пакет подготовлен для существующего проекта GitHub Pages + Supabase.
Локальная версия изменена; опубликованный сайт автоматически не обновлён.

## Изменения

- Клик по фону и Escape не закрывают формы. Кнопка закрытия спрашивает
  подтверждение, если данные изменены. При обновлении вкладки браузер предупреждает
  о несохранённых изменениях. Автосохранение не включено.
- «Сохранить черновик» сохраняет документ в базе без публикации. Укажите название
  документа; поля разделов, статей и текстовых блоков можно заполнить позже.
  При публикации проверяются обязательные поля. Черновики доступны администратору.
  Сохранение опубликованного документа как черновика снимает его с публикации.
- Раздел и статья создаются / редактируются отдельными формами из справочника.
  Форма статьи показывает название родительского раздела и поля одной статьи.
  При создании раздела / статьи внутри общего редактора кнопка «Применить» возвращает
  к документу; затем сохраните весь документ или его черновик.
- «Порядок действий»: администратор задаёт шаги сверху вниз. В попытке шаги
  перемешиваются; курсант перемещает их мышью или стрелками и подтверждает порядок.
  Ответ сохраняется на сервере. Только полностью верная последовательность даёт балл.
- «Соответствие»: каждая строка редактора — термин и правильное определение.
  В попытке независимо перемешиваются обе колонки. Старые пары сохраняют смысл,
  а ранее начатые попытки не меняются.

## Публикация через браузер

1. Распакуйте `preview/fso-editor-update.zip`.
2. В корне репозитория GitHub выберите Add file → Upload files и перетащите
   папки `site`, `supabase`, `tests` из распакованного пакета вместе с инструкцией.
   Не загружайте внешнюю папку пакета: должны обновиться существующие пути файлов.
3. Сохраните в main. Дождитесь успешного Publish FSO Center в Actions.
4. В Codespaces выполните `git pull origin main`. Если имеются несохранённые изменения,
   сначала сохраните / согласуйте их; не используйте принудительный сброс.
5. Проверьте `npm test`.
6. Разверните серверную функцию с действующей авторизацией Supabase CLI:

```bash
npx --yes supabase@latest functions deploy fso-api \
  --project-ref rnkmfpjzmvdnpijpeayw \
  --no-verify-jwt \
  --use-api
```

7. Обновите сайт Ctrl+F5. Сначала проверьте сохранение чернового материала,
   создание одного раздела и статьи, затем тренировочный тест нового типа.

Миграции SQL и пересоздание базы не требуются. Результаты и материалы сохраняются.
Не заменяйте свой `site/config.js`: он не включён в пакет.
Пакет не содержит базу, пароли, ключи или настройки аккаунта.
